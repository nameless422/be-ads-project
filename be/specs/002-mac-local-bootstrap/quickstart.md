# Quickstart

## First Run On macOS

```bash
git clone git@github.com:nameless422/be-ads-project.git
cd be-ads-project/be
make mac-start
```

## Check Only

```bash
./scripts/ops/mac_local_start.sh --check-only
```

## Start Without Verification

```bash
./scripts/ops/mac_local_start.sh --skip-verify
```

## Reset Local Containers Before Starting

```bash
./scripts/ops/mac_local_start.sh --reset
```
