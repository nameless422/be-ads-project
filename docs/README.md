# Docs Guide

`docs/` 按用途分为 4 类：

- `architecture/`
  当前生效的架构设计、ADR 和系统分层说明。
- `runbooks/`
  平台接入、联调、切换到真实环境的操作手册。
- `roadmap/`
  研发阶段路线图和后续迭代顺序。
- `archive/`
  历史设计草案，仅作背景参考，不作为当前实现的直接依据。

当前优先阅读顺序：

1. `architecture/adr-001-target-stack.md`
2. `architecture/distributed-raw-transform-bi-architecture.md`
3. `roadmap/implementation-roadmap.md`
4. `runbooks/google-ads-test-to-real-runbook.md`
